# Bersihinihh Prototype

Prototype klik mobile untuk tugas Kewirausahaan Teknologi UNAI.

## Struktur

- `index.html` - seluruh HTML, CSS, dan JavaScript, siap dijalankan langsung
- `vercel.json` - konfigurasi clean URLs; tidak perlu build

## Deploy ke Vercel

1. Di Vercel, pilih Add New > Project dan import repository `Philiphutahaean/bersihinnih`.
2. Framework Preset: **Other**.
3. Root Directory: **./**.
4. Build Command: **kosong/default**.
5. Output Directory: **kosong/default** (jangan isi `dist`).
6. Klik Deploy dan buka URL hasil deployment di HP.

## Batasan

Prototype hanya simulasi. Pesanan, pembayaran, unggahan foto, dan penilaian tidak dikirim atau disimpan pada server. Kode BRS-0042 merupakan contoh.
