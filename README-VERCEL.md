# Bersihinihh Prototype

Prototype klik mobile untuk Tugas-10 Kewirausahaan Teknologi UNAI.

## Isi

- `dist/index.html` — seluruh antarmuka HTML, CSS, dan JavaScript
- `vercel.json` — konfigurasi direktori output untuk Vercel

## Deploy ke Vercel

1. Simpan file proyek ini di repository GitHub milik kelompok atau unggah folder proyek dengan Vercel CLI.
2. Di dashboard Vercel pilih **Add New > Project** lalu impor repository tersebut.
3. Pilih **Framework Preset: Other**.
4. **Root Directory:** direktori yang memuat `vercel.json`.
5. **Build Command:** kosongkan (tidak memerlukan build).
6. **Output Directory:** `dist` (juga ditetapkan dalam `vercel.json`).
7. Klik Deploy, kemudian uji alamat baru di HP.

Prototype ini belum mengirim pesanan, menyimpan unggahan foto, atau memproses pembayaran sungguhan. Semua form berjalan di memori halaman browser. Nomor WhatsApp bisnis belum ditetapkan.

Sesudah deployment Vercel berhasil, perbarui link pada PDF Tugas-10 dan nonaktifkan akses publik versi lama jika memang tidak lagi diperlukan.
